# MCD-Project — Dual-band (0.5 / 2 GHz) Wilkinson power divider

Final report: **report.pdf** (source `report.tex`, figures in `report_assets/`).

| Deliverable | Files |
|---|---|
| 1. Mathematical analysis / S-matrix | `report.pdf` Sec. 2, `wilkinson_model.m` |
| 2. Lossless MATLAB model + plots | `wilkinson_dualband_design.m` (uses `wilkinson_model.m`) |
| Layout synthesis (MATLAB) | `em_layout.m` (microstrip widths/lengths), `coupled_line_synthesis.m` (coupled pair W, S) |
| 3. EM simulation (Ansys HFSS 2025 R2) | `em/build_hfss.py` (builds + solves the model), `em/wilkinson_dualband.aedt` / `.s3p` (nominal), `em/wilkinson_dualband_tuned.aedt` / `.s3p` (final, L = 7.6 nH) |
| 4. Validation MATLAB vs HFSS | `validate_em.m` (set `EM_FILE` to either `.s3p`) |

Run order in MATLAB: `wilkinson_dualband_design` → `em_layout` → `coupled_line_synthesis` → `validate_em`.

Rerun HFSS (window must be allowed to open — Student licence):
`"C:\Program Files\ANSYS Inc\ANSYS Student\v252\AnsysEM\ansysedtsv.exe" -RunScriptAndExit em\build_hfss.py`
(geometry numbers come from `em/hfss_params.py`, generated by `em/make_params.py`).

`em/*.py` are Python twins of the MATLAB scripts (run with the CPython bundled in AEDT) used to
produce the report figures when MATLAB was not available.
